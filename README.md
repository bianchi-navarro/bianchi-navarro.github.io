# Bianchi Navarro — Cybersecurity Portfolio

English-language professional portfolio covering security operations, criminalistics, DFIR and OSINT interests, education, vendor credentials, and practice profiles.

## Website

https://bianchi-navarro.github.io/

Static HTML and CSS. No build step, external fonts, analytics, or runtime dependencies. GitHub Pages publishes from `main` and the repository root. Keep `.nojekyll` at the root.

## Edit the portfolio

- Edit `index.html` for profile text, experience, tools, credentials, education, and links.
- Edit `assets/styles.css` for the visual design.
- Keep vendor credentials, industry certifications, and complementary education separate. Label courses, completion certificates, and expired credentials accurately.
- Add only reviewed public information and approved contact details. Never upload private CVs, workplace material, or internal review documents.

## Add a lab or CTF write-up

1. Copy `labs/template/` to `labs/your-project-name/`.
2. Fill in the actual objective, authorized scope, environment, tools used, methodology, findings, sanitized screenshots, mitigations, practical value, lessons, and attribution.
3. For OSINT, record source URLs, observation dates, corroboration, and uncertainty. Keep confirmed facts separate from inferences.
4. Replace the title, description, category, status, and all placeholders. Retain a draft label until reviewed, and remove `noindex` only when the case is ready to publish.
5. Add the project name, category (DFIR, Cybersecurity, Ethical Hacking, or OSINT), a short description, and a relative link to the home page. Include a link to the project repository on GitHub when available.
6. Check mobile and desktop layouts, keyboard navigation, local links, captions, and alternative text before committing.

The unfilled template is a reusable source file and is not listed as a completed project on the home page.
