# Profiling a Windows Host with Registry Explorer

[Read the lab report](https://bianchi-navarro.github.io/labs/windows-registry-profiling/)

DFIR lab 01. Initial host profiling using the `SOFTWARE` and `SYSTEM` registry hives from a Windows lab VM. The report documents the conflicting version fields, the two timestamp formats, and the control set used to locate the computer name.

- `index.html`: the report served by GitHub Pages.
- `evidence/`: cropped screenshots in report order. The hostname is withheld in the final figure. No registry hives or original documents are included.
