# Profiling a Windows Host with Registry Explorer

[Read the lab report](https://bianchi-navarro.github.io/labs/windows-registry-profiling/)

DFIR lab 01. The report follows the examination in order: locate the hives, validate the Windows build, compare the installation timestamps, then resolve the control set before reading the computer name. It explains how each finding can inform an investigation and what still needs corroboration.

- `index.html`: the report served by GitHub Pages.
- `evidence/`: seven screenshots with the application context retained. The report links each figure to its full-size file. Product identifiers and the lab computer name are masked in the published copies. No registry hives or original documents are included.
